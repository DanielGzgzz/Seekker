================================================================================
SYNTHETIC MARKET ANALYSIS - CREDENTIALS & SETUP GUIDE
================================================================================

Welcome to the Synthetic Market Analysis platform! This project allows you to test product ideas against a statistically accurate, AI-generated synthetic Israeli population (which you can modify for other global populations).

When you run the app out of the box (`./ignite.sh`), it operates in MOCK MODE by default. This lets you see the dashboard and UI without needing a credit card or cloud account.

If you want the REAL AI insights and full functionality, follow these steps to acquire and configure the necessary credentials.


--------------------------------------------------------------------------------
1. GOOGLE CLOUD VERTEX AI CREDENTIALS (REQUIRED FOR AI ANALYSIS)
--------------------------------------------------------------------------------
We use Google Vertex AI (specifically Gemini 1.5 Pro) to simulate focus groups and generate the structured JSON reports.

HOW TO ACQUIRE:
1. Go to the Google Cloud Console: https://console.cloud.google.com/
2. Create a new Project (or select an existing one).
3. Enable the "Vertex AI API" for your project. Note: You will need to enable billing on your GCP account.
4. Generate a Service Account Key (JSON file):
   - Navigate to "IAM & Admin" -> "Service Accounts".
   - Click "Create Service Account" and give it a name (e.g., "synthetic-market-ai").
   - Grant it the "Vertex AI User" role.
   - Click on the newly created service account -> "Keys" tab -> "Add Key" -> "Create new key" -> "JSON".
5. Download the JSON file and save it securely on your machine (e.g., inside this project folder, but NEVER commit it to GitHub).

HOW TO CONFIGURE:
1. Copy the `.env.template` file to `.env`:
   `cp .env.template .env`
2. Open `.env` and set `GOOGLE_APPLICATION_CREDENTIALS` to the absolute path of the downloaded JSON file.
3. Set `PROJECT_ID` to your GCP Project ID.
4. Run the app: `source .env && ./ignite.sh`


--------------------------------------------------------------------------------
2. STRIPE API CREDENTIALS (OPTIONAL - FOR B2B PURCHASING ONLY)
--------------------------------------------------------------------------------
If you are deploying the full SaaS backend (`app/main.py`) and testing the API key purchasing flow (`client/buy_api_key.py`), you need Stripe.

HOW TO ACQUIRE:
1. Go to the Stripe Dashboard: https://dashboard.stripe.com/
2. Ensure you are in "Test mode" (toggle in the top right corner).
3. Navigate to "Developers" -> "API Keys".
4. Copy your "Secret key" (starts with `sk_test_...`).
5. Navigate to "Developers" -> "Webhooks" -> "Add endpoint".
   - Set the Endpoint URL to your local tunneling address (e.g., ngrok) or your deployed Cloud Run URL + `/webhook` (e.g., `https://your-app.com/webhook`).
   - Listen for the `checkout.session.completed` event.
   - Click "Add endpoint", then reveal and copy the "Signing secret" (starts with `whsec_...`).

HOW TO CONFIGURE:
1. Open your `.env` file.
2. Set `STRIPE_API_KEY` and `STRIPE_WEBHOOK_SECRET` with the values you copied above.


--------------------------------------------------------------------------------
3. RUNNING THE APP
--------------------------------------------------------------------------------
Once your `.env` file is populated, ALWAYS source it before igniting the app so the credentials load into your environment:

$ source .env
$ ./ignite.sh

If everything is correct, the app will detect the credentials, and the "Mock Mode" warning will disappear from the Streamlit dashboard!
